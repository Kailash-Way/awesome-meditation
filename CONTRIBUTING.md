## Code of Conduct

This project follows a Code of Conduct. By participating, you are expected to uphold this code. Please read the [Code of Conduct](CODE_OF_CONDUCT.md) before contributing.

## How to Contribute

### Adding a Resource

1. **Fork** this repository
2. **Clone** your fork locally
3. **Add** the resource to the appropriate section in `README.md`
4. **Commit** your changes with a clear message
5. **Push** to your fork
6. Submit a **Pull Request**

### Adding a New Category

If you want to add a new category/section:
1. **Open an Issue** first to propose the new category
2. Once approved, add the new section to `README.md`
3. Add it to the **Contents** table
4. Include at least **5 resources** in the new section
5. Submit a Pull Request

### Fixing Errors

Found a broken link, typo, or error?
1. Fix it in `README.md`
2. Submit a Pull Request with a description of what was fixed

## Guidelines

### What Belongs in the List

- Meditation, mindfulness, and spiritual wellness resources
- High-quality, useful content for meditators of all levels
- Resources that are freely accessible (free apps, free courses, books with ISBN)
- Scientific research on meditation and mindfulness
- Tools that help with meditation practice
- Communities for meditation practitioners

### What Does NOT Belong

- Spam or self-promotion (unless the resource is genuinely valuable)
- Affiliate links
- Paid apps without a free tier (exception: industry-leading apps like Calm, Headspace)
- Resources unrelated to meditation, mindfulness, or spiritual wellness
- Duplicate entries

## Submission Format

Use this format for all entries:

```markdown
- [Name](URL) - Short description.
```

**Example:**
```markdown
- [Insight Timer](https://insighttimer.com/) - Largest free meditation community with 100k+ guided meditations.
```

### Rules
1. **Alphabetical order** within each section (when possible)
2. **Capitalize** the resource name
3. Keep descriptions **concise** (under 100 characters)
4. Use an **em dash** (`—`) for longer descriptions
5. Include the author/creator for books

### Book Format
```markdown
- [**Book Title**](GoodreadsURL) — Author Name
```

## Quality Standards

- **Relevance**: The resource must be directly related to meditation, mindfulness, or spiritual wellness.
- **Quality**: Resources should be high-quality, well-maintained, and widely respected.
- **Accessibility**: Prefer resources that are freely accessible.
- **Accuracy**: Ensure all links work and descriptions are accurate.
- **Uniqueness**: Check that the resource is not already listed.

## Pull Request Process

1. **Check** for existing PRs that might address the same resource
2. **Use a clear PR title** (e.g., "Add: Insight Timer to Apps > Free")
3. **Reference** any related Issues in your PR description
4. **Wait** for review — maintainers will review your PR as soon as possible
5. **Make changes** if requested by reviewers

### PR Title Format
- `Add: [Resource Name]` — for adding a new resource
- `Fix: [Description]` — for fixing a broken link or typo
- `New Section: [Section Name]` — for adding a new category
